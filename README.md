# MacroTrack para Android

Descargas oficiales de la app **MacroTrack**: tu diario de comidas, macros y escaneo de fotos con IA.

## Descargar

**[⬇ Descargar la última versión (APK)](https://github.com/knlykos/macrotrack-releases/releases/latest/download/macrotrack.apk)**

Versiones anteriores y notas de cambios: [Releases](https://github.com/knlykos/macrotrack-releases/releases).

## Instalar

1. Abre el enlace de descarga desde tu teléfono Android.
2. Abre el archivo `macrotrack.apk` descargado.
3. Si Android lo pide, permite **Instalar apps desconocidas** para tu navegador o gestor de archivos.
4. Toca **Instalar** y entra con tu correo o con Google.

Para actualizar, descarga e instala la nueva versión encima de la anterior; tus datos se conservan.

Requiere Android 8.0 o superior.
